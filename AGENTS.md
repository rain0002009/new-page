## Agent skills

### Supported browser

Target Chrome only. Before implementation, browser testing, or issue acceptance work, read `docs/agents/platform.md`.

### Issue tracker

Use GitHub Issues. Before issue work, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triage, read `docs/agents/triage-labels.md`.

### Domain docs

Use single-context domain docs. Before codebase exploration, read `docs/agents/domain.md`.

### UI styling

Use UnoCSS utilities first and tailwind-variants for reusable variants. Before creating or changing UI, styles, or UnoCSS configuration, read `docs/agents/ui-styling.md`.

### Versioning

Before finalizing a shipped extension change, changing a version, or preparing a store submission, read `docs/agents/versioning.md`.
