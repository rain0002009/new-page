# 交互动效验收

日期：2026-11-12

规格：[交互动效优化](specs/motion-polish-2026-11-12.md)

## 实现

- 使用现有 dnd-kit、浏览器动画接口及 UnoCSS，未增加依赖。
- 共享弹窗保留退出阶段的内容，进入约 220ms、退出约 180ms，遮罩同步淡入淡出。中断后从当前可见状态继续；保留原生 dialog 的焦点约束，表单打开后聚焦输入，关闭后恢复焦点。
- 待选预览使用稳定的容器，对尺寸与两种呈现方式进行约 220ms 的过渡。进入收藏内容区域变为链接卡片，离开时变回待选条目。
- 落位约 320ms；冻结尚未结束的形态过渡，再接入落点的位置、尺寸及内容。布局改变期间跟随真实目标；仅在目标变化时更新关键帧，避免反复重设导致浮层无法结束。
- 收藏块、卡片及待选条目增加布局位移和新增淡入；收藏块内容高度变化约 240ms，动画结束后恢复自然布局和溢出显示。
- 快捷建块阈值为 600ms，仅进入落点时出现提示和进度；达到阈值后提示“松手新建收藏块”。离开、取消、换位置和滚动使落点变化时重置，松手才提交。
- 系统减少动态效果时，跳过位移、形态和淡入淡出动画，仍保留建块等待与文字反馈。
