沿用 `master` 分支。审查基线为 `8d9b0a5`，功能提交为 `2c45f27`；审查覆盖该提交及后续工作区修复。

## 交付行为

- 待选网页收集成功保存到本地后，关闭准确的原标签页，包括置顶标签页；保留其他同网址标签页。拖动开始时冻结网页信息，原页关闭仍可保存，原页跳转则保留新页面并提示。本地保存失败保留原页，关闭失败保留收藏并提示。
- 进入整个中间区域即显示链接卡片预览；已有收藏块中显示插入占位，最终顺序与占位一致。普通空白松手取消，待选条目增强底色。
- 已有收藏块之间及首尾各有 24px 快捷建块落点。进入显示淡线，同一落点连续停留 2 秒后发光并提示“松手新建收藏块”；松手原子保存展开的“新收藏”和当前链接。离开、切换、取消及滚动离开重置计时。
- 支持待选网页与已有收藏链接；移动已有链接保留身份、备注、待办标记及独立待办顺序，原空块保留。空空间没有落点，必须先通过按钮创建收藏块；Todo、搜索、整个收藏块和空间的拖动继续各自的用途。

## Spec

另一独立代理审查规格符合性，发现两项 P2 问题，均已修复并复核：

1. 历史或并发数据中相同的排序值会使实际落位与占位不一致。浏览器先复现失败；无有效数字间隙时，按当前可见顺序重新编号并更新修改时间，再插入。卡片与收藏块插入、Todo 顺序和重开保留均已验收。
2. 窄窗口中的抽屉和拖动卡片遮住“松手新建收藏块”。提示改为测量落点位置后渲染至页面顶层，在拖动预览上方显示，检查了实际截图。

补充回归发现快捷建块落点会截获整个收藏块的键盘方向键。浏览器先复现失败；统一键盘坐标选择，按来源类型筛选有效目标，收藏块、空间和 Todo 只选择同类型目标。独立代理复核未发现新的具体缺陷。

Spec：初始 2 项 P2，补充 1 项键盘回归；最终未处理 0 项。
