# 电子书采用本机 IndexedDB 与夸克目录双端存储，单本删除直接永久清理

2026-11-27 明确电子书（Book）作为收藏块下的独立实体类型，同时排除把 EPUB 二进制内容写入 `收藏.json` 或仅保存磁盘 `FileSystemFileHandle` 句柄的做法。Chrome 重启会重置文件句柄授权且部分拖拽仅暴露临时 `File`，因此本地阅读模式与夸克网盘模式统一将 EPUB 字节缓存在本机 IndexedDB，只在 `收藏.json` 保存书名、存储模式、夸克 `fid` 与阅读进度，避免原文件移动失效或反复弹窗授权，代价是仅本地模式的书籍无法在其他已同步设备打开。

上传到夸克网盘时通过分片上传（上限 200MB）存入 `页墟收藏/电子书/<书名>--<稳定ID>.epub`，不复用 WebDAV 或单独绑定另一套夸克账号，未连接夸克时禁用网盘上传或回退弹窗提示。单本删除电子书卡片沿用 [ADR 0004](0004-note-deletion-boundary.md) 笔记策略绕过回收站直接永久删除，并联动清理本机 IndexedDB 与夸克文件；随空间或收藏块删除时则共同进入回收站，待彻底清理或到期后释放二进制资源。
