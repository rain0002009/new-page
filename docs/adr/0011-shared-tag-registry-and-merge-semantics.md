# 标签目录采用稳定 ID 引用并定义并发合并语义

2026-11-25 用户选择将标签作为全收藏库共享、可独立存在的目录对象保存。标签内部使用稳定 ID，业务身份仍是“名称 + 颜色”；收藏块、链接卡片和笔记卡片各自保存有序的标签 ID 引用，显示顺序按添加顺序排列。

两个设备同时创建同名同色标签时，同步后自动合并为一个标签并重映射引用；同一实体并发添加不同标签时，标签引用取并集。标签删除优先于并发编辑或挂载，删除会移除全部引用、不进入回收站，但保留用户不可见的同步墓碑以传播永久删除。

这保证了跨设备复用与统一身份，代价是标签目录和引用关系需要进入现有同步快照，并在合并阶段处理重复身份、引用并集和删除优先级。
