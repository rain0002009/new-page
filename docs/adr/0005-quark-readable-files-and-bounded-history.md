# 夸克统一目录内保存可读文件与有限同步历史

历史提交方案已被 [ADR 0006](0006-quark-current-files-only.md) 取代；以下保留为原决定记录。

2026-11-13 用户要求减少夸克中的 JSON 文件，并让每篇笔记成为可直接使用的 Markdown 文件；本决定取代 ADR 0002 的无限历史保留和 ADR 0003 的不生成独立 Markdown。所有文件统一放在「页墟收藏」中：`收藏.json` 是当前完整数据的可读副本，`笔记/标题--稳定标识.md` 保存当前有效笔记正文，`同步历史/` 保存同步提交；Markdown 为扩展单向发布的副本，云端手工修改不回写扩展，本地文件与在线文件仍作为独立来源处理。

夸克缺少已验证的条件覆盖能力，因此同步仍以不可变提交为准，每份提交携带设备版本向量和合并基线。已合并旧提交只保留最近 10 份，加当前提交；未合并分支保留至用户解决，清理不再依赖祖先文件完整存在。超出保留窗口且没有共同基线的并行差异显式交由用户选择，代价是可能增加冲突，但不会直接按时间覆盖内容。

可读文件先上传临时副本并按文件 ID 下载校验，再更名并清理旧副本；同步成功前必须完成发布，失败由后续同步修复。云端历史和已有导出备份仍可能含已删除内容；单篇笔记删除后移除当前 Markdown，父级删除恢复时重新发布 Markdown，沿用 ADR 0004 的删除边界。用户确认项目尚未上线，不需要旧版数据迁移；直接使用新格式，旧测试文件与扩展缓存由用户清理。
