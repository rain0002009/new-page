# 扩展直接访问夸克，使用独立版本文件保存收藏

历史无限保留方式先被 ADR 0005 替代，现已由 [ADR 0006](0006-quark-current-files-only.md) 移除云端同步历史。

用户在 2026-11-10 明确选择直接使用夸克接口，取代 ADR 0001 中以 WebDAV 作为主要存储的决定；本地优先、离线编辑和账号隔离继续适用。复用用户自建服务中的 QuarkClient，在扩展后台适配扫码、Cookie 轮换、上传签名与下载，不依赖该 Worker 部署或 WebDAV 的 ETag。WebDAV 保留为已有数据的连接与迁移入口。

每次保存上传一个包含父版本引用、内容散列和完整业务数据的独立文件，再通过文件 ID 下载校验。不同设备同时保存会形成分支，下一次读取按共同祖先进行合并，同一内容冲突沿用版本选择界面；不执行缺少服务端原子保护的整文件覆盖。云端历史文件暂不自动删除，以便支持分支合并与恢复；因此回收站 30 天清理作用于当前业务数据，历史备份中的旧内容仍可能存在，设置页需要说明。代价是云端文件随保存次数增长，后续清理必须保留仍需参与合并的祖先。

网盘登录信息只存在扩展本地存储；可见界面、业务文件、导出与日志均不包含 Cookie。Chrome 临时请求头规则只针对本扩展发出的具体请求 URL，处理完成后删除，不修改正常浏览器页面的请求。专用「页墟收藏」目录的 fid 作为账号缓存标识，目录被删除后不静默认作原账号空数据。
