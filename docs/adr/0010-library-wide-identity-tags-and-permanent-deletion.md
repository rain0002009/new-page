# 标签以名称和颜色作为全库身份并永久删除

2026-11-25 用户选择让标签跨收藏块、链接卡片和笔记卡片共享，并以“名称 + 颜色”作为全收藏库唯一的业务身份：名称和颜色都相同才是同一个标签，同名不同色是不同标签。修改名称或颜色原地作用于所有引用；如果修改后的名称和颜色已经存在，则合并两个标签及其引用，不保留重复标签；失去全部引用的标签仍保留在全局目录中，直到用户明确删除。删除标签时立即解除全部引用并永久移除，不进入回收站。“透明”只表示筛选时忽略颜色，不是标签颜色，也不能用于快速创建标签。

这一边界保证了用户要求的标签身份判断和跨收藏块、卡片的统一筛选，代价是标签改名、改色和删除都是全局操作，且删除不可通过回收站恢复。
