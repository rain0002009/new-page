# 新标签页设计

> 2026-11-10 交互与视觉增量：手动添加和点击批量收藏被移除；所有拖拽对象整体可拖，空备注留空；Todo 改为可打开标题、可完成和独立排序的纵向清单，保留左右区域；浅色主调接入 fluid-prism，清理冗余文案。上述要求以 [最新增量规格](../specs/ui-refinement-2026-11-10.md) 为准，下文保留原始设计背景。

状态：需求问题已澄清，已汇总截至 2026-11-10 的全部回答。规格已发布为 Issue #1，测试边界已确认；功能现已实现，验证与审查记录见 docs/implementation-review.md。

## 技术与视觉

- 使用 React、TypeScript、UnoCSS、tailwind-variants，包管理器使用 pnpm。
- 拟采用 TanStack Query 管理读取、后台刷新和请求状态；持久化业务数据与未上传修改单独保存，具体实现由开发阶段确定。
- 奶白背景、浅灰卡片、低饱和鼠尾草绿强调色，明亮但不刺眼；卡片采用适中密度的自适应网格。

## 页面结构

- 左侧为功能区，显示昵称、空间，以及 Todo、搜索和设置入口。
- 中间为内容区，默认显示空间列表中第一个空间；调整空间顺序会改变默认空间。
- 右侧为待选区域，实时显示本页面所属 Chrome 窗口中可收藏的标签页。
- Todo、搜索和设置只替换中间区域，左右两栏保留。
- 窄窗口时右侧改为抽屉。

## 空间、收藏块与链接

- 首次新建数据时，创建“我的空间”和一个空收藏块。
- 空间和收藏块均支持创建、重命名、删除与拖拽排序；至少保留一个空间。
- 收藏块有名称，可折叠，包含多个收藏链接。
- 链接卡片默认显示图标、标题、备注；缺失图标时使用占位图标。
- 卡片提供编辑、删除和书签图标形式的待办开关。书签只表达待办标记是否点亮；不展示独立的已完成状态。
- 支持手动添加链接，以及编辑网址、标题和备注。
- 点击链接卡片在新标签页打开网址。
- 拖拽可改变链接顺序、跨收藏块移动，但不能跨空间移动。
- 折叠的收藏块可以接收拖入，添加后展开。
- 相同网址可以重复收藏，包括在同一个收藏块内；重复条目独立管理。首版不提供去重或整理功能。

## 待选区域与自动保存

当前交互以[待选区域操作规格](../specs/tab-inbox-actions-2026-11-12.md)及[拖拽收集规格](../specs/drag-collection-2026-11-12.md)为准：支持自动时间命名的一键收藏、单条直接关闭及同步浏览器排序。保存本地成功后关闭被收藏的原页；下文命名弹窗和保留原页等条目为原始设计背景。

- 只展示和收藏 HTTP/HTTPS 网页，不支持浏览器设置页、扩展页、新标签页等特殊页面。
- 将标签页从待选区域拖入收藏块，直接使用该条目的标题、网址和图标创建收藏链接，不弹窗、不要求补充信息或确认；备注初始为空，原标签页继续保留。
- 新增、编辑、拖拽、删除、待办开关等内容改动自动保存本地，并自动安排远端同步，不提供单独的“保存”按钮。
- 保留右上角批量收藏图标。点击后弹窗只填写新收藏块名称，将当前窗口中可收藏的网页创建为当前选中空间中的一个新收藏块；保存后原标签页继续保留。
- 编辑已有链接时可以使用弹窗修改信息，改动自动保存，不提供单独的“保存”按钮。手动添加链接有独立入口，不影响拖入即收藏的操作。
- 批量收藏入口和自动保存并存：前者创建内容，后者持久化每次内容改动。

## Todo

- Todo 是收藏链接自身的布尔标记，不创建独立任务，不支持手动创建普通待办。
- 每张卡片的书签图标独立点亮或熄灭；相同网址的不同收藏条目互不影响。
- Todo 页只展示全部空间中书签点亮的卡片。
- 点击完成会熄灭该链接的书签，并立即从 Todo 页消失；收藏链接本身保留。
- 不提供已完成列表。再次加入 Todo 必须到收藏处找到对应卡片并点击书签图标。

## 搜索

- 搜索全部空间中链接的标题、网址和备注。
- 结果标明所属空间与收藏块。
- 搜索结果支持链接操作，以及定位到原收藏块。

## 删除与恢复

- 删除单个链接、收藏块或空间时，内容进入回收站，保留 30 天。
- 删除空间前展示内容数量并确认；至少保留一个空间。
- 删除父级时子项整体进入回收站；相关链接从 Todo 页移除。
- 恢复收藏时恢复其原待办标记。

## WebDAV、本地数据与同步

- 初始夸克网盘方案因直接扩展接入能力未证实，按用户备选改用标准 HTTPS WebDAV；具体服务商尚未指定，连接时验证实际能力。
- 首次无数据时显示配置页，填写昵称、服务器地址、用户名和密码或应用专用密码。
- 已有缓存时优先展示本地数据，再在后台刷新。
- 离线或认证失效时仍允许增删改；修改保存在本地并显示待同步，恢复连接后自动上传。
- 多设备修改不同条目时自动合并；同一内容有冲突时保留两个版本，让用户选择。
- 昵称和收藏数据同步到远端；WebDAV 密码只保存在当前设备，备份不包含密码。
- 切换 WebDAV 时提供“切换到另一份数据”和“迁移当前数据”；切换隔离两边缓存，迁移先读取目标，目标非空时确认合并，避免直接覆盖。

## 设置

- 修改昵称和 WebDAV 配置。
- 查看同步状态并手动同步。
- 导入、导出备份。
- 查看回收站并恢复内容。
