# 页面交互与视觉调整

日期：2026-11-10。状态：规格已发布为 [GitHub Issue #2](https://github.com/rain0002009/new-page/issues/2)，实现与审查修复已提交。用户已确认沿用现有浏览器测试边界；实施中追加的 dnd-kit 要求已纳入实现。最终检查见 [实现及验证记录](../ui-refinement-validation.md)。

## 用户已明确的要求

- 新增收藏链接只通过右侧待选区域拖入，移除手动填写链接的入口。现有“收藏当前窗口”批量创建入口也不符合“只能拖入”的限制。
- 所有支持拖拽的对象使用整体拖拽区域，移除专用拖拽图标。内部按钮与输入仍需可正常操作，嵌套对象应拖动用户实际抓取的对象。
- 用户在实施中指定使用 dnd-kit 优化所有拖拽，提供拖动预览、有效落点反馈及鼠标、触摸与键盘支持。
- 验收追加：移除卡片底部剩余的移动图标和空白；拖动保留完整内容及原始宽高，落点显示占位，待选网页放入收藏时提供尺寸过渡。
- 搜索收藏改为弹窗，保留侧栏和 `/` 快捷键入口；关闭后保留当前页面，定位时关闭并跳转原收藏块。
- 未填写备注时留空，不展示“还没有备注”等占位文案。
- Todo 改为常见的纵向待办清单，保留标题打开网页、完成和上下拖拽排序，移除编辑、删除、移动、定位等额外操作。
- 移除“改动自动保存”“一点点收集，一点点生长”等冗余提示和装饰文案，只保留必要提示。
- 使用用户提供的 fluid-prism 库提升整个页面的视觉效果。

## 本轮已明确的选择

1. Todo 标题可以点击，并在新标签页打开原网页。完成沿用现有语义：熄灭该收藏链接的待办标记，立即从 Todo 移除，原收藏保留；不展示已完成列表。
2. Todo 使用独立于收藏位置的全局顺序，拖拽后的顺序需要持久保存。新加入或完成后重新加入的待办排到末尾。
3. Todo 页面保留右侧待选区域，以维持各页面布局稳定。向 Todo 内容区域拖入待选网页不创建收藏或待办，不显示可接收拖放的状态。
4. 沿用当前浅色主调，在原有配色基础上加强 fluid-prism 流体效果，不切换为深色蓝紫主题。
5. fluid-prism 覆盖全页背景，提供明显的鼠标流体波纹和色散；面板配合光泽与悬浮反馈，文字、按钮和 Todo 行保持清晰稳定，正常点击和拖拽不受影响。

## 提示保留范围

移除口号、问候、引言、重复操作教学和常驻自动保存说明。保留操作标签、输入校验、影响数据的确认、权限/连接/同步错误和必要的简短空状态，不增加新的装饰文案。

## 与已有设计的关系

本轮要求替代旧设计与规格中的手动新增、点击批量收藏和 Todo 复用链接卡片的要求。保留现有浅色主调与 Todo 两侧区域；正式增量规格见 [页面交互与视觉调整规格](../specs/ui-refinement-2026-11-10.md)。

现有存储与同步 ADR 不受本轮交互和视觉要求影响。本轮尚未产生需要新增 ADR 的架构取舍；已将用户确认的“待办顺序”写入 CONTEXT.md。

## 2026-11-12 拖拽收集调整

本节记录本次访谈已经确认的规则；与前文冲突的原标签页保留和拖动预览规则由本轮替代。用户调用 to-spec 后，规格已发布为 [GitHub Issue #3](https://github.com/rain0002009/new-page/issues/3)，标签为 ready-for-agent。完整要求与验收以[拖拽收集规格](../specs/drag-collection-2026-11-12.md)为准，尚未开始本轮功能实现。

- 待选网页进入中间收藏内容区域后，拖动预览立即呈现为链接卡片；拖入收藏块时，与已有链接卡片一样显示占位并选择插入顺序。
- 预览呈现为卡片不等于空白区域可以接收拖放。只有已有收藏块和已触发的快捷建块位置可以接收；在其他空白处松手取消。
- 收藏链接成功保存到本地后，关闭被拖入的那个浏览器标签页，不等待云端同步。保存失败保留原标签页；关闭失败保留已保存的收藏并提示。
- 使用被拖动标签页的独立身份执行关闭，其他同网址标签页不受影响；置顶标签页同样遵循收集后关闭。原页已关闭时收藏照常完成；原页已经跳转时保存拖动开始时的信息，保留跳转后的页面并提示原页已变化。
- 已有收藏链接通过快捷建块移动到新的“新收藏”，不复制；原收藏块变空时继续保留。
- 待选条目的底色需要更明显，与背景保持清楚的视觉区分。
- 仅空间页支持这套卡片预览、插入占位和快捷建块；来源为待选网页和已有链接卡片。Todo 仅调整待办顺序，搜索结果经定位回到原收藏块后整理；整个收藏块的拖动仅调整块顺序。
- 快捷建块落点使用块间现有的 24px 间隙，以及第一块上方、最后一块下方各 24px 的触发带，不覆盖链接卡片。相邻两块共享间隙表示同一个插入位置。
- 进入触发带显示淡线，连续停留 2 秒后变成发光线并提示“松手新建收藏块”；同一间隙内移动不重新计时，离开、取消或切换间隙重置计时。未满 2 秒松手取消；满 2 秒后松手才在指示位置创建“新收藏”并放入链接。
- 新块直接展开，不弹出重命名，允许多个“新收藏”同名。没有收藏块的空间不提供快捷建块落点，必须先通过已有按钮创建至少一个收藏块。
