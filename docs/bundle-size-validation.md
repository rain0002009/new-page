# 生产包体积验证

2026-11-14，使用 Node 24.22.1、pnpm 11.25.0、Extension.js 4.1.39 构建 Chrome 生产包。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 扩展输出目录总大小 | 6,600,195 字节（6.29 MiB） | 3,924,102 字节（3.74 MiB） |
| 最大 JS 资源 | 1,355,515 字节（1.29 MiB） | 365,198 字节（356.64 KiB） |
| 文档入口 JS | 1,355,515 字节 | 30,002 字节（约 29.3 KiB） |

总输出减少约 41%。总大小按未压缩的 `dist/chrome` 文件求和，入口大小不包含异步资源与共享依赖。

## 变更

- 三种文档来源共用一个懒加载编辑器入口；未打开正文时无需加载编辑器。
- 编辑器依赖拆分为异步资源，保持代码语言原有的动态导入边界，避免固定 chunk 名称把全部语言合并。
- 编辑器样式改为显式导入已启用的功能，移除关闭的 LaTeX、AI、顶部工具栏和差异审阅样式，以及由 LaTeX 样式带入的 KaTeX 字体。
- 保留 Crepe 的语言列表、代码主题与编辑行为；未新增依赖，未提高预算或禁用构建警告。已关闭功能的部分 JS 仍可能被 Crepe 引入。

`maxSize` 是构建器的拆分目标，不是硬上限。`tests/build-budget.spec.ts` 对生产包中每个 JS 和 CSS 资源检查 1 MiB 上限，防止后续引入超大资源。

## 验证

- `pnpm build:chrome`：成功，无体积警告。
- `pnpm typecheck`：通过；项目未配置独立 lint 命令。
- `pnpm exec playwright test tests/build-budget.spec.ts`：优化前失败，优化后通过。
- 13 项 Chrome 回归通过：空文档按需加载与代码高亮、笔记保存/离线重开/导出、大纲和响应式布局、在线 Markdown、图片粘贴/拖放/编辑权交接、本地目录、文件授权/磁盘冲突/草稿恢复、新标签页本地读取及原生标签组。
- 检查笔记与图片编辑器截图，排版和图片显示正常；输出目录不再包含 KaTeX 字体文件。
