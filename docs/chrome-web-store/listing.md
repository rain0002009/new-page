## 名称

页墟 · Page Garden

## 简短描述

以空间整理收藏，用 Todo 标记待办，自动保存到夸克网盘。

## 详细描述（可复制）

把打开的网页收好，把想法留下。

页墟是一个整理网页与 Markdown 笔记的 Chrome 新标签页。用空间区分工作、学习和生活，在收藏块中把资料与笔记放在一起，让每次打开浏览器都能接着上次的思路继续。

主要功能

• 按空间与收藏块整理网页：拖动排序、编辑标题和备注，快速找到需要的资料。
• 收起满屏标签页：把当前窗口打开的网页拖入收藏，或一键收藏；内容保存成功后关闭原标签页。
• 管理 Chrome 标签组：查看、创建、重命名、换色和解除分组，支持多选与批量整理。
• 边读边记：创建 Markdown 笔记，自动保存正文，使用大纲浏览，支持导出 .md。
• 阅读本地与在线 Markdown：授权后编辑本地文件、浏览文件夹；在线 Markdown 以阅读方式打开。自动接管 Markdown 地址可在设置中关闭。
• 整理待读内容：点亮收藏链接的书签标记即可加入全局 Todo，拖动调整顺序，完成后保留原收藏。
• 跨空间搜索：按 / 搜索收藏标题、网址、备注和笔记正文。
• 本地保存与云端同步：首次连接夸克网盘或兼容的 HTTPS WebDAV 后，修改先保存在本机，暂时离线也能继续编辑，联网后重试同步。
• 备份与恢复：导入、导出 JSON 备份，恢复回收站内的链接、收藏块和空间。
• 可选图片上传：配置自己的 s.ee API Key 后，在可编辑文档中上传图片并插入公开图片链接。

开始使用

安装后打开新标签页，使用夸克 App 扫码连接收藏库，或填写自己的 HTTPS WebDAV 地址与账号。当前没有跳过连接、直接创建纯本地收藏库的入口。s.ee 图片上传需要另行配置 API Key。

数据说明

收藏和笔记先保存到本机，再同步至你连接的云端服务。夸克登录 Cookie 和 WebDAV 密码仅保存在本机扩展存储中；s.ee API Key 会随收藏库同步，并包含在导出备份中。上传至图床的图片通过公开链接访问。

链接、收藏块和空间支持 30 天回收站；单独删除一篇笔记会立即永久生效。云端不提供同步历史，已有导出备份需自行管理。卸载扩展不会删除网盘、WebDAV 或图床上的文件。

本扩展会替换 Chrome 新标签页。文件网址访问和本地文件写入需要 Chrome 的相应授权。页墟是独立项目，不代表 Google、夸克或 s.ee，也不暗示其认可或合作关系。

## 单一用途（隐私页，可复制）

通过 Chrome 新标签页整理个人网页资料：将当前窗口的标签页收集到空间与收藏块，在资料旁记录 Markdown 笔记，并通过 Todo、搜索与用户选择的云端同步继续阅读和使用这些资料。
