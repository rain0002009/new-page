# 权限与隐私后台填报

适用：src/manifest.json 与当前 1.0.0 生产构建。本文件是填报依据，不是最小权限审查已通过的承诺。

## 每项 API 权限的用途（可复制相应段落）

### storage

在当前设备保存空间、收藏块、收藏链接、Markdown 笔记、Todo、个人偏好、同步基线、冲突与未上传修改，确保离线和重开后可以继续使用。另保存用户连接云端服务所需的本机凭据以及图片清理队列。

### tabs

读取当前窗口打开标签页的网址、标题与图标，在新标签页的待选区域展示，按用户操作收藏、排序、打开和关闭网页；收藏成功后才关闭原页。也用于打开和管理笔记编辑页，以及与 Chrome 原生标签组相关的标签操作。

### tabGroups

在待选区域显示 Chrome 原生标签组的名称、颜色、折叠状态和成员。按用户操作创建、重命名、改变颜色、折叠、移动和解除标签组，保持扩展界面与浏览器中的组一致。

### webNavigation

识别主框架中本地 file: Markdown 文件的导航，在开启自动接管且取得 Chrome 文件网址访问许可时打开扩展文档阅读器。本地文件没有 HTTP 响应头，因此使用导航事件处理。

### alarms

每分钟唤醒扩展后台，重试已连接收藏库的未完成同步，并在满足延迟、同步和引用检查条件时重试图片清理。切换到另一收藏库不会移除旧库的后台重试。

### webRequest

有两个直接相关的用途：一是检查 HTTP/HTTPS 主框架中 .md 或 .markdown 地址的响应 Content-Type，仅在确认是原始 Markdown 内容时打开阅读器，避免接管 HTML 文件查看页；二是读取本扩展发出的夸克请求响应中的 Set-Cookie 和跳转信息，以完成用户主动扫码登录、会话轮换和网盘同步。响应检查不用于广告、用户画像或向开发者上传浏览记录。

### declarativeNetRequestWithHostAccess

为本扩展主动发往夸克及其上传服务的登录和网盘请求设置 API 所需的 Cookie、Origin、Referer 和 User-Agent 等请求头。临时会话规则仅匹配本扩展作为发起方、具体请求 URL 和 XHR 类型，请求结束后清理；不用于改写其他网站的内容或用户的一般浏览请求。

## 主机权限

### <all_urls>

用户可以打开任意 HTTP/HTTPS 站点上的在线 Markdown、配置自己的 HTTPS WebDAV 数据源，以及在授权后读取本地 file: Markdown 文件与目录。自动 Markdown 接管还需要检查 HTTP/HTTPS 主页面的响应类型。此权限也覆盖用户连接的夸克服务、云上传地址及可选 s.ee 图片服务。文件网址仍须用户在 Chrome 扩展详情中单独允许，本地文件写入还需要文件系统授权。

该权限范围广；仅凭上述文字不能保证通过最小权限审核。当前没有改为按需主机授权，提交前应确认各入口的用途与实际分发需求。

### https://*.quark.cn/*

用于用户主动连接的夸克二维码登录、账号信息和收藏库同步；当前固定使用 drive-pc.quark.cn、uop.quark.cn、pan.quark.cn、su.quark.cn。

### https://*.uc.cn/*

当前运输层允许的夸克登录/API 关联跳转目标。源码没有固定调用该域名的接口，是否由真实登录服务触发尚未验证；这是需要真实服务验收后决定保留或删除的声明，不能声称已经证明其必要性。

### https://*.aliyuncs.com/*

用于夸克 API 返回的动态阿里云对象存储上传地址，将用户选择同步的收藏数据与笔记副本上传到其网盘。

以上三个显式域名已被 <all_urls> 覆盖，不是额外的数据用途。此轮准备材料保留生产权限配置，未用文案替代权限最小化判断。

## 远程代码声明（待结合生产包检查后填报）

建议选“未使用远程代码”。源码入口和构建后的脚本为扩展本地文件，动态 import 用于加载包内编辑器与语法模块。夸克、WebDAV、s.ee 及 Markdown 请求读取的是用户数据、图片或文档，不作为 JavaScript 执行。最终检查结果见 validation.md；不要把远程图片或普通数据请求误报成远程可执行代码。

## 数据类型填报建议

按后台实际字段和定义复核，不能直接勾选“未收集任何用户数据”。即使开发者没有自建接收服务器，扩展仍读取并向用户选择的服务传输数据。

| 后台常见数据类型 | 当前涉及的数据 |
| --- | --- |
| 身份验证信息 | 夸克会话 Cookie、WebDAV 认证信息、s.ee API Key；Key 还进入同步和备份 |
| 个人身份信息 | 用户填写或夸克返回的昵称、所配置的 WebDAV 用户名/账号标识 |
| 网页记录（Web history） | 当前窗口标签页的 URL、标题和用户保存的收藏地址；没有读取 chrome.history 完整历史记录 |
| 网站内容（Website content） | 用户打开的 Markdown 正文、笔记、备注和所上传的图片 |

没有发现广告跟踪、分析遥测或开发者业务后端。仅凭访问文档的动作，不应额外声明键盘记录、点击监控或全站行为分析。用户可能主动在笔记里写入敏感信息，应在政策中说明其将随所选同步服务保存。

后台有关不出售数据、不将数据用于无关用途或信用评估的认证，应由开发者核对本实现与实际运营后确认。隐私政策与商店披露必须一致。

## 源码核对入口

- src/core/markdown-navigation.ts：Markdown 主框架响应与本地导航。
- src/core/quark/transport.ts：Cookie 响应、请求头会话规则及目标白名单。
- src/core/quark/auth.ts、src/core/local-workspace.ts：本机凭据与工作副本。
- src/core/workspace.ts：同步、导出、图片清理和所有数据源的后台重试。
- src/core/see.ts、src/core/hosted-images.ts：图床接口与清理队列。
- src/document/local-files.ts：IndexedDB 中的完整正文、草稿及文件句柄。
