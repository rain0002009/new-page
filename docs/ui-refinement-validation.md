## 交付行为

- 日常新增收藏仅由右侧待选网页拖入；手动新增与批量收藏入口、专用拖拽图标、空备注占位和冗余提示已移除。
- dnd-kit 统一处理空间、收藏块、收藏链接、待选网页和 Todo 的整体拖动，包含预览、落点反馈、排序过渡以及鼠标、触摸和键盘传感器。
- 按用户截图继续调整：移除剩余移动按钮及底部空白，完整对象快照保留内容与宽高，排序落点显示空占位，待选网页落下后平滑变为收藏卡片。跨块占位本身可接收投放，防止它推移目标卡片后产生落点跳动。
- 搜索改为弹窗，保留侧栏和 `/` 入口，打开自动聚焦输入；关闭保留原页面，定位时关闭并跳到原收藏块，搜索结果继续支持编辑。
- Todo 使用纵向清单，仅保留标题打开、完成和整行排序。顺序独立保存并参与现有同步，新加入或重新加入排到末尾；右侧待选区域保持显示，拖入 Todo 不产生操作。
- fluid-prism 随扩展打包，提供全页浅色流体背景、鼠标波纹与色散；真实 DOM 和玻璃面板保持可读、可操作。初始化不可用时保留基本功能，后台页面暂停效果，失效画布不会因页面重新可见而重启。
- 历史数据、备份和同步兼容新增待办顺序；夸克不可变快照先校验原始文档散列，再填充新增字段，避免误判合法旧快照损坏。

## Standards

按 code-review 技能由独立代理审阅规范与 Fowler 结构异味。未发现硬性规范违规或需要单独报告的结构异味；两轮共发现 3 项 P2 行为风险，均已修复并通过窄范围复核。

1. 拖拽整项未绑定 activator 引用，嵌套完成按钮和标题的键盘事件可能启动父项拖拽。现同时绑定 node 和 activator；真实 Chrome 中按钮空格完成、标题回车打开和整行键盘排序通过。
2. WebGL 上下文丢失后，页面重新可见可能重启已隐藏的效果。现可见性处理同时检查画布是否已失效隐藏，阻止重启。此分支通过代码复核；浏览器覆盖了 WebGL 初始化失败时的功能降级。
3. 快速连续拖动时，前一次操作完成可能调用后一次拖动的落点 resolver，导致动画持续等待。现每次拖动捕获独立 resolver，各动画按自己的快照取得对应 Promise；重叠动画对同一真实目标的隐藏采用引用计数，取消后也恢复。

Standards：累计 3 项，最严重为 P2 键盘操作被吞及连续拖动动画等待；最终未处理 0 项。
