# 特殊页面与本地文件

2026-11-12 用户确认：支持浏览器设置页、扩展页、新标签页及本地文件。此规格替代早期收藏规格与待选操作规格中“仅 HTTP/HTTPS”“隐藏特殊页面”的限制。

- 待选区域显示当前窗口内的普通网页、浏览器页面、其他扩展页面、about 页面和本地文件。所有本扩展页面及其接管的新标签页（chrome://newtab/、edge://newtab/、about:newtab），无论打开多少个都不进入待选区域；带查询参数或锚点的副本同样排除。其他窗口继续独立。
- 支持 HTTP/HTTPS、chrome://、edge://、about:、chrome-extension://、moz-extension:// 和 file://，拒绝不支持的网址类型。
- 所有支持的页面共用拖入收藏、快捷建块、一键收藏、关闭和排序行为。保存成功后按已有规则关闭原标签页；原页发生导航或移出窗口则保留。
- 收藏链接支持编辑网址、Todo、搜索、回收站、备份导入导出和同步。普通网页显示域名，特殊页面与本地文件显示完整网址；缺少标题时使用可读的网址，缺少图标时使用默认图标。
- 点击收藏、Todo 或搜索结果中的特殊页面，通过浏览器标签页接口打开；支持键盘 Enter、Ctrl/Command 点击与鼠标中键。打开失败显示提示，可再次尝试。
- 同步保存网址和元信息，不复制本地文件或安装扩展。重新打开取决于目标浏览器、扩展与文件是否仍可用。

验收覆盖真实 Chrome 的设置页、扩展管理页、about:blank、其他扩展页面、本地文件，以及普通网页回归；多个本扩展页面、新标签页入口、带查询参数或锚点的副本均被排除，一键收藏不关闭这些页面。Edge 与 Firefox 的专有页面需在对应浏览器验收。
