# 待选区域 Chrome 原生分组与双侧批量操作

## Problem Statement

用户在待选区域整理当前窗口的标签页时，无法看出 Chrome 标签组的边界，也无法直接创建、编辑、解除或拖动分组。多个网页需要一起归组、收藏或关闭时，只能逐条处理，整理结果与浏览器标签栏之间缺少完整的分组交互。

收藏块中已有的链接和笔记同样缺少多选能力，无法一次在新标签组中打开、移动到其他收藏块、移入新收藏块或删除。用户希望用一致的选择方式和底部操作栏完成这些任务，同时保持卡片布局稳定，并避免待选标签与已保存内容混在同一次批量操作中。

## Solution

待选区域展示和操作真实 Chrome 原生标签组，名称、颜色、成员、顺序及折叠状态与浏览器标签栏双向同步。通过组标题色点、左侧同色竖线及轻底色连接组内标签，让同组关系一眼可辨。标题显示名称和数量，右侧提供编辑与解除分组图标；编辑使用 dropdown 修改名称和九种原生颜色。

一键收藏旁增加一键分组按钮，将当前待选区域全部标签移入一个自动命名的新组。标签支持拖入、拖出、组内排序与组间移动，组标题支持整组拖动及折叠。

待选标签和当前空间的收藏卡片均支持多选；选择其中一侧会清空另一侧选择。图标在原固定占位切换为 checkbox，不改变卡片宽度或文字位置。选中后在主界面底部中间显示操作栏，提供已选数量、全选、取消选择及以下操作：

| 操作 | 待选标签页 | 收藏链接与笔记卡片 |
| --- | --- | --- |
| 分组 | 所选原标签移入新 Chrome 组，不弹窗，自动命名 | 新开所选内容并放入一个新 Chrome 组，不弹窗，自动命名；保留原收藏 |
| 添加到对应收藏 | 弹窗选择任意空间下的收藏块，完整保存后关闭原页 | 显示为“移动到收藏块”；弹窗选择当前空间下的收藏块，移动原条目 |
| 快速收藏 | 在当前空间顶部创建自动命名的收藏块，完整保存后关闭原页 | 在当前空间顶部创建自动命名的收藏块，移入所选原条目 |
| 删除 | 直接关闭所选标签，不进入应用回收站 | 链接进入回收站；笔记永久删除，涉及笔记时确认一次 |

## User Stories

1. 作为 Chrome 用户，我希望待选区域显示现有浏览器标签组，以便在工作台中识别分组关系。
2. 作为用户，我希望组标题展示名称、色点和数量，以便快速辨认每个组。
3. 作为用户，我希望同组标签由同色竖线与轻底色连接，以便一眼看出组内成员与组外标签的边界。
4. 作为用户，我希望待选区域与 Chrome 标签栏使用同一个原生分组，以便在任意一侧整理后得到相同结果。
5. 作为用户，我希望在 Chrome 中修改名称、颜色、成员或顺序后待选区域更新，以便不会看到过期分组。
6. 作为用户，我希望待选区域的分组修改同步到 Chrome，以便不用在两个位置重复操作。
7. 作为用户，我希望在一键收藏旁看到一键分组图标，以便快速找到整理入口。
8. 作为用户，我希望一键分组将当前待选区域全部标签放入同一个新组，以便一次整理当前打开的内容。
9. 作为用户，我希望空待选区域不能创建空分组，以便避免无效操作。
10. 作为用户，我希望一键分组将已分属不同组的待选标签合入新组，以便完整执行本次整理。
11. 作为用户，我希望多选分组只处理所选标签，以便未选中的原组成员保持归属。
12. 作为用户，我希望分组操作允许将涉及的置顶标签取消置顶后入组，以便所选标签都能完成归组。
13. 作为用户，我希望普通排序仍保留置顶状态，以便非分组操作不会意外取消置顶。
14. 作为用户，我希望新组自动命名为“分组1”等名称，以便分组时不需要填写表单。
15. 作为用户，我希望新组使用当前窗口最小未占用编号，以便默认名称容易区分。
16. 作为用户，我希望编号释放后可以复用，以便名称规则简单可预测。
17. 作为用户，我希望每个组标题右侧有编辑图标，以便快速修改名称和颜色。
18. 作为用户，我希望编辑图标打开锚定的 dropdown，以便在当前上下文完成编辑。
19. 作为用户，我希望从灰、蓝、红、黄、绿、粉、紫、青、橙九色中选择，以便与 Chrome 原生组颜色一致。
20. 作为用户，我希望通过保存按钮或 Enter 提交编辑，以便鼠标和键盘都能操作。
21. 作为用户，我希望 Esc 或点击外部取消未保存修改，以便安全放弃本次编辑。
22. 作为用户，我希望空组名被提示并阻止保存，以便组标题始终可辨认。
23. 作为用户，我希望组标题有解除分组图标，以便一次释放组内全部标签。
24. 作为用户，我希望解除分组不关闭任何成员页面，以便保留打开的内容。
25. 作为用户，我希望组标题支持折叠与展开，以便减少长列表占用。
26. 作为用户，我希望折叠状态与 Chrome 双向同步，以便两侧反映同一个组状态。
27. 作为用户，我希望拖动组标题移动完整组，以便调整整组在当前窗口中的顺序。
28. 作为用户，我希望拖标签到组内插入线即可加入该组，以便自由调整成员及其顺序。
29. 作为用户，我希望拖标签到组外插入线即可解除其归组，以便把标签移回未分组区域。
30. 作为用户，我希望能在组内排序和组间移动标签，以便按需要整理打开的网页。
31. 作为用户，我希望拖动落点显示“加入某组”或“移出分组”，以便松手前看清结果。
32. 作为用户，我希望取消拖动或无效松手不改变分组与顺序，以便安全放弃操作。
33. 作为用户，我希望整组拖动和解除分组包含组内隐藏的本扩展页面，以便组级操作与 Chrome 原生组一致。
34. 作为用户，我希望一键分组和待选多选只作用于待选中展示或选中的标签，以便不会额外操作同组隐藏页面。
35. 作为用户，我希望待选标签支持逐项 checkbox 选择，以便组合需要一起处理的网页。
36. 作为用户，我希望收藏链接与笔记卡片都支持多选，以便统一整理两种收藏内容。
37. 作为用户，我希望收藏选择可以跨当前空间的多个收藏块，以便把分散内容一起处理。
38. 作为用户，我希望收藏选择不跨空间，以便本次操作范围始终明确。
39. 作为用户，我希望 Todo 与搜索保留原有交互，以便这些页面不引入本轮多选模式。
40. 作为用户，我希望开始选择待选标签时自动清空收藏侧选择，反向操作也一样，以便不会混用两种批量操作。
41. 作为用户，我希望图标在原位置切换为 checkbox，以便不额外挤占内容宽度。
42. 作为用户，我希望 hover、选中及操作栏出现时卡片宽度、文字位置和网格列数不跳变，以便保持阅读与点击稳定。
43. 作为用户，我希望点击 checkbox 只改变选择，以便不会误开网页或启动拖动。
44. 作为用户，我希望标题保留原打开功能，以便多选入口不影响日常浏览。
45. 作为用户，我希望支持 Shift 连选，以便快速选择连续条目。
46. 作为用户，我希望底部操作栏显示已选数量并提供全选与取消选择，以便确认范围并批量调整选择。
47. 作为用户，我希望按 Esc 清空选择，以便快速退出多选。
48. 作为用户，我希望切换空间或主页面时清空选择，以便不会携带不可见的旧选择操作。
49. 作为用户，我希望拖动已选条目时整批拖动并保持原显示顺序，以便一次移动多个条目。
50. 作为用户，我希望拖动未选条目时清空原选择并只拖该条，以便单条拖动含义明确。
51. 作为用户，我希望底部操作栏在主界面下方中间出现，以便两侧批量操作使用一致的入口位置。
52. 作为用户，我希望待选多选分组不弹窗并自动命名，以便快速完成整理。
53. 作为用户，我希望添加待选标签到收藏时弹窗选择空间及其收藏块，以便将内容放到正确位置。
54. 作为用户，我希望待选快速收藏不弹窗并创建新收藏块，以便一次保存当前选择。
55. 作为用户，我希望新收藏块命名为“收藏 YYYY-MM-DD HH:mm:ss”，以便辨认收藏发起时间。
56. 作为用户，我希望新收藏块位于当前空间顶部并展开，以便立即查看结果。
57. 作为用户，我希望待选批量收藏完整本地保存后再关闭准确原页，以便不会因保存失败丢失网页。
58. 作为用户，我希望重复网址的标签分别保存并按原显示顺序排列，以便保留独立条目。
59. 作为用户，我希望原页已跳转或跨窗口后保留当前页面并提示，以便不会误关后来变化的内容。
60. 作为用户，我希望保存成功但关闭失败时保留完整收藏，以便已保存内容不会被回滚。
61. 作为用户，我希望重试未完成关闭时不会再次建块或收藏，以便避免重复保存。
62. 作为用户，我希望待选删除直接关闭所选标签，以便快速减少打开的页面。
63. 作为用户，我希望收藏侧分组在当前窗口新建一批标签并加入同一个新组，以便一起浏览所选内容。
64. 作为用户，我希望在新组中打开时不去重也不复用已打开的同网址标签，以便每次操作结果明确。
65. 作为用户，我希望所选笔记打开自身编辑页并加入新组，以便与网页一起浏览。
66. 作为用户，我希望笔记编辑页继续遵守待选过滤规则，以便待选中不出现本扩展页面。
67. 作为用户，我希望在新组中打开不改变原收藏，以便打开操作不移动或删除已保存内容。
68. 作为用户，我希望收藏侧“移动到收藏块”只提供当前空间的目标，以便沿用同空间整理规则。
69. 作为用户，我希望收藏侧快速收藏将原条目移入新收藏块，以便一次归拢分散内容而不生成副本。
70. 作为用户，我希望移动保留条目身份、备注、笔记正文、待办标记及既有待办顺序，以便整理归属不改变内容和任务状态。
71. 作为用户，我希望仅删除链接时直接将其放入回收站，以便保留恢复能力。
72. 作为用户，我希望批量删除包含笔记时只确认一次并明确永久删除篇数，以便理解不可恢复的影响。
73. 作为用户，我希望混合删除时链接仍进回收站、笔记按现有规则永久删除，以便各类内容遵循既定边界。
74. 作为用户，我希望全部成功后清空选择并收起操作栏，以便知道本次操作已经结束。
75. 作为用户，我希望取消弹窗后保留选择，以便可以重新选择操作。
76. 作为用户，我希望部分失败时只保留未完成且仍存在的条目选中并提示原因，以便有针对性地重试。
77. 作为用户，我希望浏览器外部修改、关闭和移出窗口后重新显示实际结果，以便不会误操作过期条目。
78. 作为用户，我希望桌面侧栏和窄屏抽屉提供一致能力，以便窗口宽度不影响整理。
79. 作为用户，我希望鼠标、触摸与键盘都能选择、拖动和使用图标按钮，以便沿用现有输入方式。
80. 作为用户，我希望按钮有清楚的悬停说明、无障碍名称及执行状态，以便理解用途并避免重复提交。
81. 作为用户，我希望收藏结果重开页面后仍然存在并沿用现有同步，以便整理结果可靠保存。
82. 作为用户，我希望原有一键收藏、单条关闭、收藏拖动、笔记、Todo 和搜索继续正常，以便新增整理能力不破坏现有工作流。

## Implementation Decisions

- 交付目标为现有 Chrome Manifest V3 扩展，沿用 React、TypeScript、dnd-kit、UnoCSS utilities 和 tailwind-variants。复用既有按钮、图标、弹窗、提示与动效能力，不新增依赖。
- 以领域词汇“空间”“收藏块”“收藏链接”“笔记”“待选区域”“浏览器标签组”“批量选择”“快速收藏”描述对象和动作。浏览器标签组是 Chrome 原生对象，与持久化收藏块分离。
- 修改当前窗口标签适配、待选展示、组编辑交互、拖动协调、工作台选择状态与批量操作栏、收藏目标选择、本地收藏操作及反馈模块。标签适配补充分组身份及组名称、颜色、折叠状态，提供实时查询和变化订阅。
- 原生组由 Chrome 实际状态决定，采用原生标签分组 API 与所需扩展权限；读取及监听组和标签变化，更新成员、顺序、名称、颜色及折叠状态。外部变化或失败后重新查询，不维护与真实浏览器分离的持久分组副本。
- 待选范围沿用当前窗口规则，包含普通网页、特殊页面和本地文件，排除本扩展所有页面及其接管的新标签页。其他窗口不参与本次分组或选择。
- 组标题展示色点、名称、数量，使用同色竖线和轻底色包住组内标签。编辑和解除分组均为标题右侧图标按钮，并有可访问名称及悬停说明。
- 编辑图标打开锚定 dropdown，包含名称输入、九色选择和保存按钮。颜色为灰、蓝、红、黄、绿、粉、紫、青、橙，对应原生组颜色。保存按钮或 Enter 提交，Esc 或点击外部取消未保存内容；空名称提示并阻止保存。
- 组标题支持折叠、展开与整组拖动，折叠状态与 Chrome 双向同步。解除分组直接执行，不关闭页面；空组消失遵循 Chrome 的真实生命周期。
- 一键分组位于一键收藏旁，将点击时当前待选区域的全部标签移入一个新组；空列表不可提交。多选分组将本次所选标签移入新组，未选中的原组成员保持归属。操作期间新增标签不扩大本次已固定范围。
- 新组名称严格使用“分组”加正整数，无空格；在当前窗口全部原生组名称中取使默认名称未占用的最小正整数。释放后允许复用，其他窗口名称不占用当前窗口编号。
- 明确发起分组操作时，允许为入组取消涉及标签的置顶状态；普通排序仍保持原置顶状态及置顶边界。前者是对旧“整理始终保留置顶”规则的已确认例外。
- 标签拖入组内插入线即加入并按落点排序，拖到组外插入线即移出原组，支持组内、组间和未分组区域排序。落点明确标示目标位置及“加入某组”或“移出分组”；取消或无效松手不提交变化。
- 组标题拖动与解除分组针对完整原生组，包含待选过滤掉的成员，例如笔记编辑页；组级名称、颜色和折叠也作用于整个原生组。一键分组仅针对待选展示的标签，多选操作仅针对准确选择的标签。
- 多选由工作台共享协调，同时只允许待选或收藏一侧持有选择，开始选择另一侧即清空原侧。收藏支持当前空间内跨收藏块选择链接与笔记，不跨空间；Todo 和搜索不提供多选。
- 待选条目和收藏卡片均在原图标的固定占位显示 checkbox。hover 显示时不挤占内容；选中后保持可辨认，键盘焦点和触摸也必须有可用入口。checkbox 点击只切换选择，不打开页面或启动拖拽；标题保留原打开功能。
- 原图标与 checkbox 保持一致占位，hover、选中及操作栏出现不得改变卡片宽度、文字位置或网格列数。UI 优先工具类及可复用 variants，拖动中的测量位置和尺寸沿用运行时布局机制。
- 支持逐项选择与 Shift 连选；全选限定当前选择来源，收藏侧限定当前空间。操作栏显示数量、全选、取消选择和四项批量动作，定位主界面底部中间，不挤压原内容布局。
- Esc 清空选择；切换空间或主页面清空选择。拖动已选条目时整批拖动并保留原显示顺序，拖动未选条目时清空旧选择并只拖当前条目；不隐式扩展选择到同组其他成员。
- 待选“添加到对应收藏”打开空间与收藏块目标弹窗，允许任意空间下的目标。收藏侧同位置操作显示为“移动到收藏块”，只允许当前空间目标；移动原链接或笔记，不创建副本。
- 快速收藏不打开命名弹窗，在发起时的当前空间顶部创建并展开新收藏块，名称沿用发起时本机时间“收藏 YYYY-MM-DD HH:mm:ss”。待选创建新收藏链接，收藏侧移动原内容，保持原显示顺序。
- 新建或移动后保留内容身份边界：已有链接和笔记保留身份、备注、正文、待办标记及既有待办顺序；待选保存的链接沿用新条目默认值。相同网址以独立身份保留，不去重。
- 待选批量收藏固定准确原标签快照与目标，沿用本地优先，完整本地保存成功后再关闭原页，不等待云端同步。保存失败不关闭原页，也不留下部分新收藏；原页已跳转或移出来源窗口则保留并提示，已关闭按实际完成处理。
- 原页关闭失败保留已完整保存的收藏，显示“已收藏，关闭未完成”；后续重试仅处理未完成关闭，不重复建块、复制或收藏已成功保存的条目。
- 待选删除直接关闭本次选中的真实标签，不先收藏，不进入应用回收站，沿用浏览器自身的离开页面确认及关闭失败反馈。
- 收藏侧“分组”是在当前窗口按原显示顺序新开所选内容并放入一个新原生组，不复用或去重已有同网址标签。笔记打开自身托管编辑页并入组；编辑页继续被待选过滤。此操作保留所有原收藏内容及状态。
- 收藏链接删除进入回收站；笔记单独删除按已接受的 ADR 0004 永久删除。混合批量删除包含笔记时统一确认一次，明确“永久删除 N 篇笔记”，链接仍进入回收站；仅链接时直接执行。
- 全部成功后清空本次选择并收起操作栏；取消弹窗保留选择。部分失败时刷新实际状态，仅保留未完成且仍存在的条目选中并提示；失效、外部关闭、删除或移出窗口的条目不得由同网址其他条目替代。
- 执行中提供忙碌状态并阻止重复提交。浏览器多步操作可能部分成功，反馈与重试必须基于已发生结果，不展示虚假的全成功或自动重复已经完成的动作。
- 浏览器组身份、实时成员、标签身份与临时选择不进入收藏持久化数据、导出、备份或云同步，不新增持久化浏览器分组 schema。新收藏与已有内容移动沿用现有本地保存、同步、账号隔离和冲突机制。
- 不修改已接受的笔记删除和本地优先架构边界；本次是现有 Chrome 标签与收藏操作的交互扩展，无新增架构 ADR。

## Testing Decisions

- 采用已有最高层测试边界：通过真实 Chrome 扩展的新标签页界面执行用户操作，观察待选、收藏、Chrome 真实标签组与标签状态，并在重开后核对本地结果。延续已确认的桌面侧栏、窄屏抽屉、鼠标、触摸、键盘验收范围；不增加新的产品测试边界。
- 好的测试验证用户可见行为、浏览器实际结果及可靠保存，不断言组件内部 state、reducer 分支或工具类字符串，不以直接调用内部批量操作函数代替用户输入。
- 通过同一扩展界面边界覆盖标签适配、分组呈现、组编辑 dropdown、选择协调、批量操作栏、目标选择弹窗、拖动协调、本地收藏操作与错误反馈，避免为每个内部模块各建一套重复测试边界。
- 复用现有真实扩展加载和受控网页夹具。现有先例覆盖一键收藏、特殊页与本扩展页过滤、同网址独立条目、置顶边界、准确原页关闭、跳转与跨窗保护、写入与关闭失败、拖动排序、窄屏、键盘和触摸；沿用这些方式扩展新分组和多选场景。
- 验证 Chrome 与待选之间名称、九色、成员、顺序及折叠状态双向变化；覆盖已有组、未分组标签、外部重命名与重排、成员退出后空组消失，以及组内存在被过滤的笔记编辑页。
- 验证一键分组和多选分组的不同范围、跨原组重组、置顶取消、未选成员保留、空列表、重复点击、发起后新开标签及其他窗口排除。验证当前窗口最小未占用编号、重命名释放、删除复用及其他窗口同名不干扰。
- 通过实际点击与键盘验证 dropdown 保存、Enter、Esc、点击外部取消、空名称提示、九色选择、焦点及执行状态；验证解除分组保留全部成员打开。
- 通过真实拖动验证组内排序、拖入组、拖出组、组间移动、整组排序和多选整批移动，核对预览归属、插入位置、松手后的待选与 Chrome 顺序，覆盖取消、无效落点及外部状态变化。
- 验证两侧 checkbox 的固定占位和两侧互斥、链接与笔记混选、当前空间跨收藏块、Shift 连选、全选、取消、数量、Esc、页面与空间切换；确认 Todo 和搜索不提供多选，触摸和键盘也可使用选择入口。
- 对 hover、焦点、选中、操作栏出现前后的真实布局进行几何比较，验证卡片宽度、文字位置与网格列数不跳变。覆盖桌面与窄窗口，确认底部操作栏不会遮挡关键操作。
- 两侧四项操作分别覆盖正常路径、空范围、目标范围与顺序。验证待选目标可跨空间、已有收藏目标限当前空间，快速收藏命名取发起时本机时间、顶部展开，以及移动后身份、备注、正文、待办标记与顺序保持。
- 收藏在新组打开覆盖已有同网址标签、重复网址、链接与笔记混选、笔记编辑页入组及其待选过滤，核对每次均新开、原收藏不改变；故障下核对实际成功项与未完成项反馈。
- 复用必要故障注入覆盖本地写入失败、保存后关闭失败、浏览器分组或移动失败、原页跳转、关闭或移出窗口。验证先完整保存后关闭、不丢失、不误关、不留下虚假状态，以及重试不重复建块、保存或打开已完成项。
- 删除覆盖仅链接、仅笔记和混合选择；验证一次确认准确显示笔记篇数、取消保留选择、链接回收站恢复、笔记永久删除，以及已打开笔记编辑页沿用既有停止写回被删除内容的边界。待选删除只关闭所选标签。
- 验证全部成功清空选择并收起操作栏，取消保留选择，部分失败仅保留未完成且仍存在的条目；浏览器外部变化后刷新实际结果并移除失效选择。
- 重开新标签页验证新收藏和移动结果已本地持久化；复用既有同步验证收藏结果及待办状态，确认浏览器组身份和临时选择未进入收藏导出、备份或云端数据。
- 回归既有一键收藏、单条关闭、普通置顶排序、收藏与笔记单条拖动、快捷建块、Todo、搜索及笔记生命周期。实施完成后执行项目类型检查、Chrome 生产构建及相关真实扩展验收；本规格不宣称新增功能已通过验收。

## Out of Scope

- Chrome 以外浏览器的适配、构建或专项验收。
- 汇总多窗口标签、跨窗口拖动或跨窗口统一编号。
- 跨空间选择或移动已有收藏卡片；Todo 和搜索结果多选。
- 自建独立于 Chrome 的待选分组、保存原生组身份或实时选择到收藏数据、跨设备同步浏览器标签组。
- 完整浏览器会话备份与恢复、按历史组还原收藏、复用已打开的同网址标签或网址去重。
- 把本扩展页面加入待选列表；组标题操作完整原生组的已确认范围不改变待选过滤规则。
- 普通排序自动置顶或取消置顶；仅明确发起分组时采用取消置顶入组的例外。
- 收藏侧快速收藏复制原条目，或将“分组”解释为新建收藏块。
- 一键分组、所选分组及快速收藏的命名弹窗，或解除分组时关闭页面。
- 将笔记单独删除改为进入回收站，或追溯清理已有云端历史与用户导出备份。
- 同步架构、账号体系、云端数据格式、主题设置或无关页面重构；新增依赖及扩展商店发布。

## Further Notes

- 规格依据 2026-11-14 三轮设计访谈：第一轮 Q1～Q4 逐项确认，后两轮 Q5～Q10 与 Q11～Q13 均由用户回复“全部采用”。设计已收口，本次按 to-spec 整理并发布，不重新访谈。
- 用户明确修正收藏侧“分组”为在新 Chrome 标签组中打开所选内容，快速收藏为移入新收藏块；这两项语义必须保持区分。
- 本规格扩展旧待选区域规格此前排除的 Chrome 分组、批量选择与整批拖动范围；明确的分组取消置顶例外优先于旧“整理始终保留置顶”约定，其余旧保护规则继续适用。
- 当前实现已有真实当前窗口待选、一键收藏、本地保存后关闭原页、单条关闭及排序、同空间收藏移动和链接/笔记卡片；尚无原生组呈现及完整双侧多选。本任务发布可实施规格，不表示功能已交付。
- 领域词汇表已补充浏览器标签组、快速收藏和批量选择；沿用 ADR 0004 的笔记永久删除边界和既有本地优先决策。
- Issue 应标记 ready-for-agent，保持开启以供后续实现；实现完成后在该 Issue 记录实际验证证据并按项目规则关闭。
