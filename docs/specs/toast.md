# 共享 Toast 通知

2026-11-14 用户要求创建 Toast 组件，以后错误和其他提示统一使用该组件。

- 新标签页与文档页共用 `src/shared/Toast.tsx`，入口挂载 `ToastProvider`，调用处使用 `Toast` 提供消息、类型、关闭回调及可选操作。
- 错误采用 `alert`，成功和普通通知采用 `status`；消息不会抢走当前输入焦点。
- 相同内容与类型合并显示，多个消息堆叠；窄窗口内保持完整可读。
- 错误持续显示，用户可手动关闭；成功及普通提示 5 秒后关闭，鼠标悬停或键盘聚焦时暂停计时。
- 原生弹窗打开后通知仍可见、可点击；关闭提示不关闭弹窗。
- 保留重试保存、重新授权和打开扩展设置等修复操作；本地版本冲突的正文比较与选择保留独立区域，避免关闭通知后丢失处理入口。
- 加载进度、保存状态、只读说明和持续同步状态属于页面状态，保留所属位置；其中操作错误由 Toast 通知。

验证以 Chrome 构建、类型检查及现有操作测试为基础，并补充通知自动关闭、暂停、窄窗口和原生弹窗交互回归。

类型检查、Chrome 构建及 11 项受影响界面专项测试通过，480px 窄窗口截图已核对。最终全量 128 项中 127 项直接通过；既有并发冲突用例假设只会产生一个选择项，调整为处理全部已列出的冲突、再验证重复同步后无冲突，连续复跑 3 次通过。标准和需求两项独立静态复审均通过。构建保留原有文档入口超过 1 MiB 预算的警告。
