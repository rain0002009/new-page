# T04：待选网页通过快捷建块完成收集并关闭原页

## Parent

rain0002009/new-page#3

## What to build

待选网页使用已有的快捷建块手势，在收藏块之间或首尾连续停留 2 秒、发光后松手，创建“新收藏”并保存当前网页。本地建块与收藏全部成功后，复用准确关闭原标签页的行为，实现一次拖动完成建块、收集和减少打开的标签页。

## Acceptance criteria

- [ ] 待选网页接入同一快捷建块落点，复用 24px 触发带、淡线、连续 2 秒发光提示、松手提交及离开/取消/切换落点的重置规则，不引入另一套计时或落点语义。
- [ ] 发光前松手、发光后取消、普通空白、空空间、Todo 及搜索不会收集、建块或关闭原页；没有收藏块时仍必须先通过按钮创建一个。
- [ ] 有效松手后，在指示位置创建一个展开的“新收藏”，将拖动开始时的标题、网址和图标保存为独立收藏链接，备注为空；允许同网址收藏及同名块，不弹表单或重命名。
- [ ] 新块与收藏链接作为一次完整的本地保存；保存失败不留下空块且保留原页。仅本地保存成功后关闭被拖动的原标签页，不等待云端同步，不重复提交。
- [ ] 复用准确关闭行为：其他同网址标签页保留，置顶标签页适用；原页已关闭仍完成收藏，原页已跳转则保留新页面并提示；关闭失败保留新块与收藏并提示。
- [ ] 计时与浏览器标签页身份只存在于当前操作，不进入收藏、同步或备份数据。成功创建的块、链接及顺序参与现有本地优先保存与同步。
- [ ] 通过真实 Chrome 扩展操作验证块间和首尾建块、提前松手/取消、同网址与置顶、原页关闭/跳转、本地失败、关闭失败和离线收集；重开后检查新块、链接与顺序，并覆盖受控同步。
- [ ] 验证鼠标、触摸、键盘及窄窗口待选抽屉可完成全过程；已有块收集和已有链接快捷建块继续通过，TypeScript 类型检查及 Chrome 生产构建通过。
