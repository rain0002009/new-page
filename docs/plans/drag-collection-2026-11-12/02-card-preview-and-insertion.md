# T02：待选网页以卡片预览并按占位顺序收集

## Parent

rain0002009/new-page#3

## What to build

待选网页进入空间页的整个中间收藏内容区域时，拖动预览立即呈现为链接卡片。拖入已有收藏块时，使用与普通链接卡片一致的占位，允许直接插入开头、中间或末尾，最终持久化顺序与占位一致；待选条目通过底色与背景清楚区分。

## Acceptance criteria

- [ ] 进入空间页中间收藏内容区域即显示链接卡片预览，无需先命中已有卡片；预览保留网页标题、网址和图标。
- [ ] 在中间普通空白处可以看到卡片预览，但不会因此显示有效接收状态；松手取消，不新增收藏或收藏块。
- [ ] 拖入已有块时显示可辨认的插入占位，开头、中间、末尾的占位与提交顺序一致，不再固定追加待选来源到末尾。
- [ ] 支持块内多列链接卡片、空块和折叠块；折叠块成功接收后展开，预览、占位及落位过渡不反复切换或导致明显布局跳动。
- [ ] 已有链接卡片的排序和同空间跨块移动、跨空间限制、收藏块/空间排序及 Todo 独立顺序继续正常；搜索弹窗不承担拖入收藏。
- [ ] 适度增强待选条目底色，在现有浅色流体背景中能辨认边界，标题、图标及交互状态清楚；遵循 UnoCSS 优先及已有共享样式约定。
- [ ] 从真实拖入操作验收预览变化、空白取消、三种插入位置及最终顺序，重开页面后顺序保持；替换旧测试中悬停保持原待选高度和始终追加到末尾的期待。
- [ ] 在桌面与窄窗口抽屉中检查可见布局及底色，并覆盖鼠标、触摸和键盘拖动、点击链接与内部控件；TypeScript 类型检查、Chrome 生产构建和相关验收通过。

## Blocked by

None (can start immediately).
