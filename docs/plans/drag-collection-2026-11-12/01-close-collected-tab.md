# T01：收集成功后准确关闭原标签页

## Parent

rain0002009/new-page#3

## What to build

用户将待选网页拖入已有收藏块后，先成功保存收藏到本地，再关闭被拖动的原浏览器标签页。准确识别原页并保留拖动开始时的网页信息；其他同网址标签页不受影响，置顶标签页同样适用，失败及原页变化有明确结果。

## Acceptance criteria

- [ ] 待选条目以稳定的浏览器标签页身份区分，拖动开始时保留标题、网址和图标；普通收集继续生成独立收藏，备注为空且不弹出表单。
- [ ] 拖入已有收藏块后，确认本地保存成功才关闭准确的原标签页；不等待云端同步，离线或云端失败时仍保留已保存的收藏。
- [ ] 同网址打开多个标签页时只关闭被拖动的一个，其他标签页保留；置顶标签页同样关闭，相同网址仍允许多条独立收藏。
- [ ] 本地保存失败时原页保留并提示；关闭失败时已保存的收藏保留并提示，不回滚或重复创建收藏。
- [ ] 原标签页在拖动期间已经关闭时仍完成收藏，不将原页缺失作为关闭失败；已经跳转到其他网址时保存拖动开始时的信息，保留跳转后的页面并提示原页已变化。
- [ ] 取消拖动、无效松手或拖入 Todo 时不关闭原页。待选区域继续只显示当前窗口中的 HTTP/HTTPS 网页。
- [ ] 临时浏览器标签页身份不进入收藏持久化、同步或备份数据；已有收藏的链接身份与待办顺序不受影响。
- [ ] 通过真实 Chrome 扩展拖入流程验证普通、重复网址、置顶、原页关闭/跳转、本地保存失败与关闭失败；更新原测试中收集后仍保留原页的旧期待，并检查重开后收藏仍在。
- [ ] 鼠标、触摸、键盘及窄窗口待选抽屉可完成收集；TypeScript 类型检查、Chrome 生产构建与相关扩展验收通过。
