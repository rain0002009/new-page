# T03：已有收藏链接停留两秒后快捷建块

## Parent

rain0002009/new-page#3

## What to build

用户将已有链接卡片拖到收藏块之间或序列首尾，在同一快捷建块落点连续停留 2 秒后看到发光线，松手在该位置创建并展开“新收藏”，将原链接完整移动进去。该切片交付可实际使用的完整手势、本地原子保存及持久化结果。

## Acceptance criteria

- [x] 仅空间页已有收藏块提供落点：块间现有 24px 间隙，第一块上方及最后一块下方各 24px 触发带；不覆盖链接卡片，指向当前空间单列收藏块序列的插入位置。
- [x] 相邻两块共享间隙是同一个落点；进入显示淡线，在同一落点连续停留 2 秒后才显示发光线及“松手新建收藏块”。
- [x] 同一间隙内移动不重计时；离开、取消、切换间隙或滚动导致离开时，立即撤销发光及可提交状态并重置。再次进入必须重新等待。
- [x] 未满 2 秒在触发带松手取消，满 2 秒后继续按住也不提前写数据；仅在已触发的落点松手时提交一次。
- [x] 新块在指示位置创建，名称为“新收藏”，允许同名、直接展开、不弹重命名；原收藏链接通过移动进入新块，不创建副本。
- [x] 链接身份、标题、网址、图标、备注、待办标记及已有待办顺序保留，原收藏块变空也保留；移动仍限制在同一空间。
- [x] 新块创建与链接移动作为一次完整的本地保存；失败时原链接位置保留、不留下空新块并显示错误。成功结果参与已有持久化、备份与同步，云端失败保留本地结果。
- [x] 普通空白及没有收藏块的空间不提供落点，不创建第一个块；Todo、搜索、整个收藏块和空间拖动均不触发该手势，内部控件继续正常。
- [x] 使用真实 Chrome 拖动覆盖块间/首尾位置、2 秒前后反馈、同间隙移动、换位置、离开重进、取消和滚动，以及多次创建同名块和本地保存失败。
- [x] 覆盖鼠标、触摸、键盘、桌面和窄窗口；重开页面及浏览器后顺序保持，并通过现有受控同步在另一客户端核对新块与链接。TypeScript 类型检查、Chrome 生产构建和相关扩展验收通过。

## Blocked by

None (can start immediately).
