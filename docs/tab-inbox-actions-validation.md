# 待选区域操作验收记录

日期：2026-11-12。规格：[Issue #8](https://github.com/rain0002009/new-page/issues/8)，本地副本见 [功能规格](specs/tab-inbox-actions-2026-11-12.md)。评审基线为 `d77f97ae3ccdd2b188578cee4d7f250924a49bc4`。

## 实现结果

- 一键收藏固定点击时的待选快照、空间与本机时间，以 `收藏 YYYY-MM-DD HH:mm:ss` 创建顶部展开的新块；空空间、Todo 和设置页均可使用。新块及链接一次本地保存成功后才关闭原页，重复网址分别保留，不等待同步。
- 每个待选条目有独立关闭按钮，直接关闭准确的浏览器标签。保存后关闭会检查原网址和窗口，保留已跳转或移出窗口的页面；部分关闭失败保留完整收藏并提示。
- 待选列表支持鼠标、触摸和键盘排序，提交到浏览器实际标签顺序。置顶与普通标签分别排序；隐藏特殊页遵循浏览器正常移动规则。取消、失败和外部变更按真实浏览器状态结束。
- 桌面与窄屏共用交互，保留拖入已有收藏及快捷建块。浏览器身份、窗口和位置只用于临时交互，收藏与同步格式沿用现有流程。

## 验收边界与覆盖

沿用用户确认的真实 Chrome 扩展界面与受控 HTTPS 服务边界。通过按钮、鼠标、触摸和键盘操作，检查可见收藏、实际浏览器标签、重开本地数据及另一设备同步结果；故障注入仅用于控制保存、关闭和移动失败及执行时序。

`tests/workbench.spec.ts` 新增 14 项验收，覆盖时间格式、顶部展开和滚动定位、快照范围、双击保护、同秒同名、重复网址、置顶、空空间、跨页导航、离线、保存原子性、变化原页保护、单条关闭、双向排序、隐藏页、边界和取消、外部变更、窄屏触摸/键盘及现有夸克同步。原“无批量入口”测试按新规格更新。

键盘置顶边界测试先复现了上下键误入快捷建块的问题，再修复为待选列内上下键仅选择同类标签；横向键继续支持进入收藏区。修复后的针对性测试已通过。

## 已知测试限制

旧测试“待选预览双向变形连续，插入时卡片让位，取消后布局恢复”在针对性运行中未采到卡片移动的中间帧；使用改动前基线独立构建后运行同一测试，也在相同断言失败。本轮全量运行中该测试通过。诊断曾记录到完整 240ms 动画中间位置，未确认产品主动跳过动画，保留原实现和原断言。临时诊断与基线副本已清理。

浏览器原生离开页面确认继续由 `chrome.tabs.remove` 的原生行为处理，未增加应用确认层；自动化没有单独触发真实页面的离开确认弹窗。

全量测试暴露两处自动化等待问题，均保留最终用户行为断言：搜索定位测试等待退出中的搜索浮层卸载后再查找同名收藏链接；手写 CDP 触摸输入在读取坐标前使用 Playwright 的试运行点击等待条目稳定，并等待正确条目的拖动状态后再移动。夸克并行编辑测试全量时在登录初始化显示“登录已失效”，尚未进入并行编辑，单独复跑完整场景通过；未确认其根因，不据此声称全量首轮全绿。
