# Chrome 原生分组与双侧批量操作验证

规格：[Issue #22](https://github.com/rain0002009/new-page/issues/22)、[本地规格](specs/tab-groups-and-batch-selection-2026-11-14.md)。验证日期：2026-11-14；基线：`37660c8`。Chrome：`157.0.8103.51`。

## 实现范围

- 待选区域使用真实 Chrome 原生标签组，双向同步名称、九色、成员、顺序和折叠状态。提供一键分组、dropdown 编辑、解除分组、标签进出组与整组拖动；组级操作包含被过滤的扩展页面。
- 待选与收藏两侧的选择互斥；收藏链接和笔记可以在当前空间跨收藏块选择。图标原位切换 checkbox，支持 Shift、全选、Escape、页面切换清空和整批拖动，Todo 与搜索保留原交互。
- 底部操作栏提供分组、目标收藏块、快速收藏和删除。收藏侧分组新开内容；快速收藏移动原条目。移动保持身份、正文、备注及 Todo 顺序。涉及笔记删除时只确认一次，链接进回收站，笔记遵循 ADR 0004 永久删除。
- 收藏先完整本地保存再关闭准确原页；三种入口共用保存与待关闭记录，关闭失败重试不重复建块或保存。新开收藏页按标签身份追踪，重定向不产生重复打开。

## 验证边界

通过真实 Chrome 扩展的新标签页操作，观察界面、原生组、实际标签和重开结果。故障只注入 Chrome API、存储或网络边界；没有新增私有模块测试接口。

新增场景覆盖原生分组编辑与同步、九色与键盘折叠、隐藏成员、跨组及整组拖动、两侧多选和布局几何、混合卡片移动与持久化、新组打开重复网址和笔记、混合删除、跨空间待选收藏、失败关闭重试、原生命名失败重试，以及新开页重定向后归组失败重试。

桌面与窄屏截图已人工检查：分组色线与轻底色连接成员；checkbox 保持图标占位；底部工具栏在窄屏内换行并位于待选入口上方。

## 检查结果

- `pnpm typecheck`：通过。
- `pnpm build:chrome`：通过。构建器仍报告按需打开的文档页包体积约 1.29 MiB，超过其 1 MiB 建议预算。
- 全量 `pnpm test`：205 项运行完毕，203 项通过、2 项失败，耗时 14.3 分钟。失败分别为已有本地文件权限提示被图床通知成功提前清除，以及迁移冲突测试在两个错误提示并存时使用了不够精确的定位。
- 修复只读权限提示保护，并将迁移断言限定到目标冲突提示。最终重新构建后，集中复测 **25/25 通过**，耗时 2.2 分钟；包含上述两项失败、所有 **12 项新增场景**、保存失败、原页跳转或关闭、关闭失败重试、鼠标及键盘收集与拖拽回归。
- 两轮合计，当前 206 项场景均已有通过记录。最终补丁后复跑受影响子集，没有再次执行整套；无剩余已知失败。
