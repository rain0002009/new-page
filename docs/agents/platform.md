# 浏览器支持范围

2026-11-13 用户确认：本项目当前仅支持 Google Chrome。

- 实现、开发入口、生产构建和验收均以 Chrome Manifest V3 为目标。使用 Chrome API 与 File System Access API 完成文档功能。
- Edge、Firefox、Safari 及其他浏览器的适配、构建、兼容流程和实机验收不属于当前范围。只有用户明确扩大支持范围后才增加。
- 历史规格中的多浏览器要求由本规则替代；历史测试记录保留为事实，不构成支持承诺或当前验收门槛。
- 保留旧数据与备份的可读取性。历史收藏中的其他浏览器网址仅作为已有数据保留，不承诺在 Chrome 中可打开。
- Chrome 的文件网址访问开关、文件和目录授权、写入失败及草稿恢复仍须验收；取消其他浏览器支持不等于取消 Chrome 的授权边界。
